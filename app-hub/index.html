Connect Starnet (one time)
  1. In Starnet, open CONNECT → ABILITIES → CONNECTED SERVICES → ADD A CONNECTOR.
  2. Add one connector for each app you want your agents to use. Use the Starnet id shown above (clipforge, aimodels, otherapps) and choose HTTP.
  3. Paste that app's Address into the URL box and its Key into bearer token.
  4. Open advanced and set timeout ms to 600000 so a video can finish in one call.
  5. Click + ADD & CONNECT. Starnet should say connected, and that app's row here shows "● Connected".
Prefer one connector? Use All apps (id apphub) instead. Schedules: on each Starnet routine that uses App Hub, tick Let this routine use your connected tools. After Reset: in Starnet, CONNECTED SERVICES → that connector → ✎ EDIT, paste the new key, SAVE & RECONNECT.
